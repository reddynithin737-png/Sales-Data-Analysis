Core Architecture & Capabilities

Features of the Website

Engineered with full-stack Python Flask, Pandas data engine, and Chart.js to meet every academic and industry presentation standard.

📊

Executive KPI Dashboard

Real-Time Business Metrics

Calculates and renders 6 real-time performance indicators: Total Revenue, Total Units Sold, Average Order Value, Best Selling Product, and Monthly Growth Rate with positive/negative trend indicators.

  • ✔ Interactive Chart.js Monthly Sales Trend Line
  • ✔ Category Revenue Distribution Donut Chart
  • ✔ Regional Sales Breakdown Bar Chart
📤

Smart CSV Upload & Validator

Automated Data Hygiene

Pre-upload validation engine automatically checks uploaded files before committing rows to the database. Identifies schema mismatch, missing fields, and date format invalidations.

  • ✔ In-file Duplicate Transaction Detection
  • ✔ Cross-database Duplicate Detection
  • ✔ Row-by-Row Error Diagnostic Table
📋

Sales Records Management

Complete CRUD Operations

Comprehensive management interface for browsing, creating, editing, and deleting individual sales transactions. Features instant dynamic revenue calculation (Quantity × Unit Price).

  • ✔ Live Search by Customer, Product or Category
  • ✔ Multi-attribute Sorting (Date, Revenue, Quantity)
  • ✔ Filter by Geographic Territory & Product Type
🏆

Product & Regional Analytics

Deep Business Insights

In-depth analytical breakdown grouping transactions by product line and geographic operational regions (North, South, East, West, Central) with ranked market shares.

  • ✔ Top-Selling Product Rankings by Gross Revenue
  • ✔ Territory Performance Comparisons & Averages
  • ✔ Dynamic Category Margins and Volume Share
👑

Admin Console & User Control

Full Login Access & Impersonation

Full administrative oversight over all user accounts. The Admin can inspect all registered members and directly access any user's session with a single click.

  • ✔ Direct User Session Access: Log in as any user instantly
  • ✔ Instant Return Banner: Restore Admin session with 1 click
  • ✔ Role Promotion/Demotion & Password Reset Tools
💾

Dual Database Engine

SQLite + MySQL Support

Built-in database abstraction layer supports zero-configuration SQLite for effortless local and serverless execution, with transparent auto-switching to production MySQL.

  • ✔ Automatic schema migrations and table provisioning
  • ✔ Pre-seeded default users, products, and sales
  • ✔ Zero external dependency mode for college submissions
🖥️

Desktop GUI Application

Tkinter Desktop Client

Accompanied by a standalone native Python desktop program (app_gui.py) styled with custom ttk widgets to operate offline without running a web server.

  • ✔ Standalone Treeview table for sales records
  • ✔ Embedded Matplotlib figure charting
  • ✔ File dialog for CSV imports and database syncing
